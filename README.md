# BlinkIT Grocery Sales Analysis Dashboard

## 📊 Project Overview
## Dataset used 
- href-"https://github.com/Srushtiraul58/Excel-Project-/blob/main/BlinkIT%20Grocery%20Data%20Excel.xlsx"

This project is an **Excel-based data analysis and visualization project** using BlinkIT grocery sales data. The objective is to analyze sales performance, product categories, outlet characteristics, and key business metrics through an interactive dashboard.

## 🎯 Objectives

* Analyze overall grocery sales performance
* Track important business KPIs
* Compare sales across different outlet types and locations
* Analyze product categories and item performance
* Understand customer ratings and sales trends
* Create an interactive and easy-to-understand Excel dashboard

## 🛠️ Tools & Skills Used

* Microsoft Excel
* Data Cleaning
* Data Analysis
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Data Visualization
* Dashboard Design
* KPI Analysis

## 📈 Key Analysis

## Dashboard Used 
- href-"https://github.com/Srushtiraul58/Excel-Project-/blob/main/BlinkIT%20Dashboard.png"


The dashboard provides insights into:

* Total Sales
* Average Sales
* Number of Items
* Average Customer Rating
* Outlet Performance
* Item Category Performance
* Outlet Size and Location Analysis
* Sales Distribution

## 💡 Project Outcome

The project demonstrates how **Excel can be used to transform raw grocery sales data into meaningful business insights through data analysis, KPIs, charts, and an interactive dashboard.**
